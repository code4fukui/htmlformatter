# htmlformatter

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

A lightweight, dependency-free JavaScript tool and module for formatting HTML code with proper indentation and closing tags.

## Demo

Try it live: **[https://code4fukui.github.io/htmlformatter](https://code4fukui.github.io/htmlformatter)**

Paste your unformatted HTML into the top text area, and the formatted result will appear instantly in the bottom text area.

## Features

- **Proper Indentation:** Automatically formats HTML with consistent two-space indentation.
- **Correct Tag Closing:** Adds missing closing tags and correctly handles self-closing (void) elements.
- **Custom Element & SVG Support:** Understands custom elements (e.g., `<qr-code>`) and properly formats nested SVG content.
- **MDN-Based Validation:** Uses a list of valid HTML tags scraped from the Mozilla Developer Network (MDN) to identify standard elements.

## Usage

### Web Interface

1.  Open the [demo page](https://code4fukui.github.io/htmlformatter).
2.  Copy the HTML code you want to format into the top text area.
3.  The formatted HTML will be displayed automatically in the bottom text area.

### As a JavaScript Module

The formatter can be imported as an ES module in browsers, Deno, or Node.js.

```javascript
import { formatHTML } from "https://code4fukui.github.io/htmlformatter/formatHTML.js";

const messyHTML = `<body style="abc"><div class="a"><b>abc</b><br><img>あ</div></body>`;
const formattedHTML = formatHTML(messyHTML);

console.log(formattedHTML);
/* Output:
<body style="abc">
  <div class="a">
    <b>
      abc
    </b>
    <br>
    <img>
    あ
  </div>
</body>
*/
```

## Data Source

The formatter relies on a list of standard HTML tags to determine which elements are self-closing. This list is automatically generated by scraping the HTML elements reference on MDN.

The generated data is available here: htmltags.csv *(demo unavailable)*
